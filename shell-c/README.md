# I-am-bored

Windows only basic shell written in C.

## How to Build and Run locally
### Prerequisites
- Windows (ofc)
- GCC

### Build
Set the `bin` folder as the working directory:
```bash
cd bin
```
Then run:
```bash
ws_tools build
```

### Run
Make sure `bin` is the current working directory. Then run
```bash
ws_tools run
```
Optionally there is a `-o` option to open in a new window, like
```bash
ws_tools run -o
```
