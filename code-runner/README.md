# code-runner

Inside [src/](src/) there are the main files (runner.ts, runner-server.ts, etc.). There is also an [sdks/](src/sdks/) folder and a [rewrites/](src/rewrites/) folder:
- The [sdks/](src/sdks/) folder has sdk files per-language, which are tiny wrappers that communicate with the server. Taking an sdk file will use the newest version of the runner, but you will need to copy the [runner.js](src/runner.js) and [runner-server.js](src/runner-server.js) files (src/ files not in any subfolders), autogenerated from the `.ts` equivalents, copied into the same directory as the sdk, and will require Node installed on your computer (preferrably v24+ for the performance improvements).
    - To start the server you can either run the [runner-server.js](src/runner-server.js) file manually, or call `RunnerClient.StartServer()` (or the equivalent in your language's SDK).

- The [rewrites/](src/rewrites/) has full rewrites of the runner in those languages. The version of the runner they are is listed on a comment on the 3rd line. You can check this with the latest runner version either in the [package.json](package.json) under `"version"`, or in the [runner.ts](src/runner.ts) file on line 3. For obvious reasons, some languages will fall behind or be deprecated entirely—indicated at the top of affected files in a comment.

- No files in either folder require external (not built-in) dependencies to function.

# Usage
> [!IMPORTANT]
> You don't need the runner-server.js file if you're using the TypeScript, JavaScript, or any other runner.* files in [rewrites/](src/rewrites/)
