# Remaking types

Fun type stuff that I experiment and have fun with.

The `npm` folder is a folder for npm package recreations that I try to make without looking at the type code, and just looking at type through usage, so usually a lot worse than the original, and probably missing stuff from what I've done of them.
> [!NOTE]
> I am not affiliated with any of these packages, I just chose them because I thought they'd be fun to try and remake.

The `everything` folder is exactly what you think. Everything. I'm going to try and strongly type as many things as I physically can. Will this be impossible to create even a single object for? Yes. Will I make TypeScript and VSCode cry? That's the goal.

The `fun` folder is just random types I made that are kinda cool and fun to use and look at. Still no practical like everything else in this project.
