# CSS Injector Chrome Extension
A simple custom CSS injector chrome extension.

## Installation
Since I don't want to pay money to get this on the chrome web store, you'll have to install manually. To do this, follow these steps:
1. Enable developer mode. To do this, go to your browsers extension page (for example on Google Chrome it's `chrome://extensions`). Then, somewhere on the page (top-right chrome, bottom left edge, etc.), you will see a toggle for developer mode. Make sure that is set to `on`.
2. Hit the button, usually labelled `Load unpacked`. Select the [src](src/) folder, and then ok.
3. **Done!** You now have this extension installed and can use it the same way as every other extension.
