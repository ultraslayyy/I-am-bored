# I-am-bored

Remaking types from npm packages because I'm bored and why not.
I am not affiliated with any of these packages, I just chose them because I thought they'd be fun to try and remake.

_experimentation is a folder for me to experiment with cool typings, without recreating a package.

In each folder, I will specify whether I used the same type names or not. Mainly for import reason. For example `express` I will use the same names for types, but I won't actually look at how the types work.
