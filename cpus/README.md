# CPUs

Just some CPUs I like to make for fun. Each CPU I make is made with a new letter of the alphabet as the first (for instance [atlas](./atlas/) is the first I've made, `bora` (TBC) will be the second, etc. This does exclude the DLS folder, which is made in Digital Logic Sim rather than SystemVerilog like the others ([DLS/01](./DLS/01/) is the first I've ever made). To check which order I made those in relation to these, you'll just have to check commit dates sorry).

## Tools I use

- Simulator: Verilator
- Waveform viewer: GTKWave
- Synthesiser: Yosys
- FPGA: None (I don't have one)
